# stacks/azure-subscription-baseline

The deployable unit that hardens one subscription. It composes two modules,
in order, into one plan and one state file:

1. `resource-group` creates the baseline resource group, with an optional
   CanNotDelete lock, when the stack is asked to create the workspace.
2. `subscription-baseline` sets the Microsoft Defender for Cloud plans,
   sends the subscription's activity log to a Log Analytics workspace (looked
   up by name, or created in the group above), and assigns initiatives by
   display name with an enforcement mode and a non-compliance message.

This is a catalog stack ([ADR 0017](../../docs/adr/0017-three-kinds-of-stack.md)).
Its cells live under `tenants/azure/<tenant>/subscriptions/<sub-name>/azure-subscription-baseline/`,
one per subscription, each with its own state file, and the subscription is
addressed by the `subscription.hcl` locator above the cell and never by a
value in it.

## The model

```
subscription.hcl  -->  root.hcl  -->  provider "azurerm" { subscription_id }
                                              |
                          data.azurerm_subscription.current (discovered)
                                              |
        +----------------------+--------------+--------------------+
        |                      |                                   |
  Defender plans     diagnostic setting "activity-log"    initiative assignments
  one per type       --> workspace (found, or created     by display name, with
  Standard | Free        in the baseline group)           enforcement mode
```

A cell says which plans are on, where the activity log goes, and which
initiatives apply. It contains no subscription ID, no workspace ID, no
definition ID, and no scope: the module discovers the subscription from the
provider, resolves the workspace and every initiative by name, and writes
exclusions from resource group names.

## Two shapes of cell

**The subscription has no workspace.** `create_workspace = true`, a
`baseline_resource_group`, and a `log_analytics_workspace` with no
`resource_group_name`. The stack creates the group (locked if
`delete_lock = true`), the workspace in it, and the export to it. The
workspace is `prevent_destroy` in the module and the group is
`prevent_destroy` in its module, so dropping either from the cell fails the
plan rather than deleting the retained activity log.

**The subscription already has one.** `create_workspace = false` (the
default), no `baseline_resource_group`, and a `log_analytics_workspace` with
the `resource_group_name` it is looked up in. The stack creates the export
and nothing else. A baseline group is refused in this shape because nothing
would be put in it.

The validations name both rules with the value to change.

## What this stack refuses

- A Defender resource type the provider does not know, a tier other than
  `Standard` or `Free`, and a sub-plan or extensions on a `Free` plan.
- An activity log category outside the eight Azure defines, and an empty
  list.
- An initiative parameter the initiative does not declare (a precondition
  names the declared ones), a parameter value that is not a string, and an
  enforcement mode other than `Default` or `DoNotEnforce`.
- Two assignments with the same name, and an assignment name outside 1 to 64
  letters, digits, hyphens, and underscores.
- A workspace location when the workspace is looked up, and none when it is
  created; a resource group name for a created workspace, and none for a
  looked-up one; a baseline group without `create_workspace`, and
  `create_workspace` without a baseline group.
- A managed identity on an assignment. There is no input for one, so an
  initiative with `DeployIfNotExists` or `Modify` effects is assigned to
  report, not to remediate, and Azure may refuse to assign it at all. The
  default initiative, the Microsoft cloud security benchmark, audits only.
- A scope ID, a workspace ID, or a definition ID. Every one is a name.

## Provider configuration

`versions.tf` declares `required_providers` only. The `provider "azurerm"` and
`provider "azuread"` blocks are generated by Terragrunt from `tenant_id` and
`subscription_id`, which `tenants/azure/root.hcl` reads from `ARM_TENANT_ID`
and, under `subscriptions/<sub-name>/`, from that directory's
`subscription.hcl`. The identity is a GitHub OIDC federated credential in CI
and the Azure CLI login on a laptop. The stack can therefore be planned
against any subscription with no code changes.

The apply identity needs Security Admin (Defender plans), Monitoring
Contributor at the subscription (the diagnostic setting), Resource Policy
Contributor (the assignments), and, for the created shape, Contributor on
the subscription to create the group and the workspace plus
`Microsoft.Authorization/locks/write` for the lock (Owner or User Access
Administrator on the group, or a custom role with that one action). Owner
covers all of it and is more than any of it needs.

## A cell

A cell for this stack looks like this. The committed one,
`tenants/azure/corp/subscriptions/sub-example-prod/azure-subscription-baseline/terragrunt.hcl`,
differs in the details of its Defender plans and workspace settings.

```hcl
include "root" {
  path = find_in_parent_folders("root.hcl")
}

terraform {
  source = "../../../../../../stacks/azure-subscription-baseline"
}

inputs = {
  create_workspace = true

  baseline_resource_group = {
    name        = "rg-example-baseline"
    location    = "eastus"
    delete_lock = true
  }

  log_analytics_workspace = {
    name              = "law-example-prod-activity"
    retention_in_days = 365
  }

  defender_plans = {
    CloudPosture    = {}
    KeyVaults       = {}
    Arm             = {}
    VirtualMachines = { subplan = "P2", extensions = { AgentlessVmScanning = {}, MdeDesignatedSubscription = {} } }
    StorageAccounts = { subplan = "DefenderForStorageV2", extensions = { OnUploadMalwareScanning = { CapGBPerMonthPerStorageAccount = "5000" }, SensitiveDataDiscovery = {} } }
    Dns             = { tier = "Free" }
  }

  policy_assignments = {
    microsoft-cloud-security-benchmark = {
      policy_set_display_name = "Microsoft cloud security benchmark"
      non_compliance_message  = "This resource does not meet the Microsoft cloud security benchmark. The platform security team owns exceptions."
    }
  }

  tags = {
    owner = "platform-security"
  }
}
```

The same cell for a subscription whose workspace already exists drops
`create_workspace` and `baseline_resource_group` and names the group:

```hcl
  log_analytics_workspace = {
    name                = "law-example-security"
    resource_group_name = "rg-example-monitoring"
  }
```

## Standalone use without Terragrunt

```hcl
provider "azurerm" {
  features {}
  # tenant_id, subscription_id, client_id read from ARM_* environment variables
}

provider "azuread" {}

module "azure_subscription_baseline" {
  source = "./stacks/azure-subscription-baseline"

  tenant_id       = "00000000-0000-0000-0000-000000000000"
  subscription_id = "00000000-0000-0000-0000-000000000000"

  create_workspace = true

  baseline_resource_group = {
    name     = "rg-example-baseline"
    location = "eastus"
  }

  log_analytics_workspace = {
    name = "law-example-prod-activity"
  }

  defender_plans = {
    CloudPosture = {}
    KeyVaults    = {}
  }
}
```

## Inputs

| Name | Type | Description |
|------|------|-------------|
| `tenant_id` | `string` | Entra tenant ID, from the environment via root.hcl. |
| `subscription_id` | `string` | The subscription, from the locator via root.hcl. |
| `create_workspace` | `bool` | Create the workspace in the baseline group (true) or look it up (false, default). |
| `baseline_resource_group` | `object` | `{ name, location, delete_lock, tags }`; required with `create_workspace`, refused without. |
| `log_analytics_workspace` | `object` | `{ name, resource_group_name, retention_in_days, daily_quota_gb, internet_ingestion_enabled, internet_query_enabled, tags }`. |
| `activity_log_categories` | `list(string)` | Categories sent; default all eight. |
| `defender_plans` | `map(object)` | Plans keyed by resource type: `{ tier, subplan, extensions }`. Default `{}`. |
| `policy_assignments` | `map(object)` | Initiatives keyed by logical name. Default: the Microsoft cloud security benchmark, enforced. |
| `tags` | `map(string)` | Tags on the group and the workspace the stack creates. |

## Outputs

| Name | Description |
|------|-------------|
| `subscription_id` | GUID of the subscription, discovered. |
| `baseline_resource_group` | `{ id, name, location, locked }` or null. |
| `baseline_resource_group_lock_id` | The lock's ID, or null. |
| `log_analytics_workspace` | `{ id, name, workspace_id, resource_group_name, location, created }`. |
| `activity_log_diagnostic_setting_id` | ID of the subscription's diagnostic setting. |
| `activity_log_categories` | Categories sent, sorted. |
| `defender_plans` | Resource type to `{ id, tier, subplan, extensions }`. |
| `policy_assignments` | Key to `{ id, name, display_name, policy_set_display_name, policy_set_definition_id, enforcement_mode }`. |
| `policy_set_definition_ids` | Initiative display name to definition ID. |
