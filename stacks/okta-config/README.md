# stacks/okta-config

The deployable unit for an Okta tenant's authentication baseline. It composes four
modules into one plan and one state file:

1. `network-zone` creates the trusted and blocked network zones.
2. `session-policy` builds the sign-on policy, referencing zones by logical key.
3. `mfa-policy` builds the MFA enrollment policy.
4. `password-policy` builds the password policy.

Tenant cells under `tenants/okta/` point at this stack and provide values only.

## What this stack does not manage

Users, groups, group memberships, and applications are owned by the directory of
record and by Okta provisioning. This stack reads group IDs with the `okta_group`
data source so policies can be scoped by name, and it never hardcodes an ID. If a
group named in a tenant cell does not exist, the plan fails early with a clear error
rather than creating a policy that applies to nobody.

## How zones are referenced

Rules name zones by the logical key used in `network_zones`, for example
`zones_included = ["corp-egress"]`. The stack maps keys to IDs through the
`network-zone` module output, which also gives Terraform the dependency edge it needs
to create zones before rules. A validation block rejects unknown keys before the plan
reaches the API.

## Provider configuration

`versions.tf` declares `required_providers` only. The `provider "okta"` block is
generated by Terragrunt from tenant inputs (`okta_org_name`, `okta_base_url`) and the
API token is read by the provider from the `OKTA_API_TOKEN` environment variable. The
stack can therefore be planned against any tenant with no code changes.

## Standalone use without Terragrunt

```hcl
provider "okta" {
  org_name = "example-org"
  base_url = "oktapreview.com"
  # api_token read from OKTA_API_TOKEN
}

module "okta_config" {
  source = "./stacks/okta-config"

  okta_org_name = "example-org"
  okta_base_url = "oktapreview.com"

  network_zones = {
    corp-egress = {
      name     = "Corporate egress"
      type     = "IP"
      gateways = ["203.0.113.0/24"]
    }
  }

  session_policy = {
    name            = "Workforce sign-on"
    priority        = 1
    groups_included = ["Everyone"]
    rules = {
      anywhere = {
        name         = "Anywhere"
        priority     = 1
        mfa_required = true
        mfa_prompt   = "ALWAYS"
      }
    }
  }

  mfa_policy = {
    name            = "Workforce MFA enrollment"
    priority        = 1
    groups_included = ["Everyone"]
    authenticators = {
      okta_verify = { enroll = "REQUIRED" }
    }
    rules = {
      default = { name = "Enroll at sign-in", priority = 1 }
    }
  }

  password_policy = {
    name            = "Workforce password"
    priority        = 1
    groups_included = ["Everyone"]
    rules = {
      default = { name = "Self-service", priority = 1 }
    }
  }
}
```

## Inputs

| Name | Type | Description |
|------|------|-------------|
| `okta_org_name` | `string` | Org subdomain. |
| `okta_base_url` | `string` | okta.com, oktapreview.com, okta-emea.com, okta.mil. |
| `network_zones` | `map(object)` | Zones keyed by logical name. |
| `session_policy` | `object` | Sign-on policy with group names and rules. |
| `mfa_policy` | `object` | MFA enrollment policy with authenticators and rules. |
| `password_policy` | `object` | Password policy with settings groups and rules. |

## Outputs

| Name | Description |
|------|-------------|
| `zone_ids` | Logical key to zone ID. |
| `group_ids` | Group name to ID for every referenced group. |
| `session_policy` | `{ id, name, rule_ids }` |
| `mfa_policy` | `{ id, name, rule_ids }` |
| `password_policy` | `{ id, name, rule_ids }` |
